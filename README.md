# Trick or Treat (and Proof) — CC0 Halloween comic

Entry for [poidh bounty #1500](https://poidh.xyz/base/bounty/1500) — a four-panel Halloween comic
starring characters from a CC0 collection, in a single image.

- `comic.png` — the finished comic (1600×1760, four panels)
- `comic.html` — the source (hand-written SVG) used to render it

The joke flips "pics or it didn't happen": a ghost tries to scare a kid, gets asked for proof,
agrees to a selfie — and does not appear in the photo.

Characters are original drawings in the Nouns (CC0) style. The comic is dedicated to the public
domain under CC0 1.0.
